# Анализатор дисков

## Описание

**Анализатор дисков** — приложение с графическим интерфейсом, разработанное на **WPF (.NET)** для операционных систем Windows.

Программа автоматически определяет все доступные логические диски компьютера и отображает информацию о каждом из них:

- букву диска;
- общий объем;
- занятое пространство;
- свободное пространство;
- процент заполнения;
- визуальный индикатор заполненности в виде ProgressBar.

Также предусмотрена возможность обновления списка дисков без перезапуска приложения.

---

## Функциональные возможности

- Автоматическое определение всех подключенных логических дисков.
- Отображение:
  - общего объема диска;
  - свободного пространства;
  - занятого пространства;
  - процента заполнения.
- Визуальное отображение заполненности с помощью ProgressBar.
- Кнопка **«Обновить»** для повторного считывания информации о дисках (например, после подключения флеш-накопителя).
- Обработка ошибок при обращении к недоступным дискам.

## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone https://github.com/Vladislav-Baksheev/DiskAnalyzer
```

2. Открыть решение (`.sln`) в Visual Studio.

3. Собрать проект (**Build → Build Solution**).

4. Запустить приложение (**F5** или **Ctrl+F5**).

ИЛИ

1. Скачать установщик из Releases.
   
2. Следовать инструкциям установщика.
   
3. Запустить приложение на рабочем столе или в папке, выбранной при установке.
